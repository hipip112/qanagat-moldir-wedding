# Сохранение ответов гостей в Google Таблицу

## 1. Создайте таблицу

Откройте Google Drive, создайте новую Google Таблицу и назовите её, например, `Қанағат & Мөлдір — RSVP`. Первый лист можно оставить с названием `Лист1`.

## 2. Добавьте Apps Script

В таблице откройте **Расширения → Apps Script**. Удалите код из редактора и вставьте весь код из файла `google-apps-script.gs`. Нажмите **Сохранить**.

## 3. Опубликуйте скрипт

В правом верхнем углу нажмите **Deploy → New deployment**. В поле типа выберите **Web app**. Установите:

- **Execute as:** Me;
- **Who has access:** Anyone.

Нажмите **Deploy**. Google может попросить разрешить доступ к таблице: выберите свой аккаунт, затем **Advanced → Go to project → Allow**. Скопируйте URL, который заканчивается на `/exec`.

## 4. Вставьте URL в сайт

Откройте файл `script.js` и найдите:

```js
const sheetEndpoint = 'PASTE_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE';
```

Замените только текст внутри кавычек, например:

```js
const sheetEndpoint = 'https://script.google.com/macros/s/ВАШ_ID/exec';
```

Сохраните файл и заново загрузите обновлённый сайт на Netlify или GitHub Pages.

## 5. Проверьте запись

Откройте опубликованный сайт, заполните имя, выберите вариант ответа и количество гостей. Нажмите кнопку RSVP. Через несколько секунд в таблице должна появиться новая строка с четырьмя колонками: время, имя, ответ и количество гостей.

Если строка не появилась, проверьте, что URL заканчивается именно на `/exec`, доступ установлен как **Anyone**, а в `script.js` не осталось значение `PASTE_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE`. После изменения доступа иногда нужно создать новое развертывание.

## Важно

Ссылка Web app доступна публично, но саму Google Таблицу можно оставить закрытой: гости отправляют данные через скрипт и не получают доступ к таблице. Не публикуйте ссылку на редактирование таблицы.

WhatsApp продолжает работать параллельно и открывает готовое сообщение для хозяев. Номер WhatsApp меняется в `script.js` в строке `whatsappNumber`.
