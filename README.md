# Қанағат & Мөлдір — Үйлену тойы

Статическая одностраничная пригласительная страница на казахском языке.

## Публикация на Netlify

Перетащите папку проекта в Netlify Drop или подключите GitHub-репозиторий. Файл `netlify.toml` уже содержит настройку публикации из корня проекта.

## Публикация на GitHub Pages

Загрузите файлы в репозиторий, откройте **Settings → Pages**, выберите ветку `main` и папку `/ (root)`, затем сохраните. Главная страница — `index.html`.

## RSVP через Formspree

Форма собирает обязательное имя, выбранный ответ и количество гостей и сохраняет их в Formspree. WhatsApp из формы убран по просьбе владельца сайта.

В сайт добавлена присланная песня в MP3. Музыка пытается запуститься после первого касания экрана и также управляется кнопкой на первом экране. Полностью автоматический звук при открытии телефонами обычно блокируется браузером без действия пользователя. Лепестки теперь падают с разными формами, размерами, цветами и плавным покачиванием.

На странице также есть обратный отсчёт до 28 ноября 2026 года, медленная плавная прокрутка к блокам и мягкое появление секций. Ответы RSVP подключены к Formspree через Endpoint `https://formspree.io/f/xljjgawa`; подробная проверка описана в `FORMSPREE-SETUP.md`. Google Apps Script оставлен в архиве как альтернативный вариант.

## Файлы

- `index.html` — разметка сайта;
- `styles.css` — дизайн и адаптивность;
- `script.js` — календарь и интерактивная форма;
- `manus-routes.json` — карта маршрутов для предпросмотра;
- `netlify.toml` — настройки Netlify.
- `assets/hero-wedding.webp` и `assets/floral-detail.webp` — свадебные изображения;
- `assets/wedding-instrumental.mp3` — фоновая инструментальная музыка.
